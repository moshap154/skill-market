# miniprogram-development

## Công việc

Phát triển, gỡ lỗi, xem trước, kiểm thử và phát hành Mini Program WeChat

## Mô tả

Skill phát triển Mini Program WeChat (miniprogram-development) trong repo TencentCloudBase/skills: hướng dẫn làm, gỡ lỗi, xem trước, kiểm thử, phát hành và tối ưu dự án Mini Program (小程序开发、调试、预览、发布), gồm cấu trúc dự án và cấu hình (project.config.json, appid, miniprogramRoot, tabBar, routing/navigation, icon assets), quy trình WeChat Developer Tools Nightly (wechatide CLI), preview/upload bằng miniprogram-ci, gỡ lỗi console/network, đẩy tin nhắn (消息推送) và trả lời tự động tin nhắn dịch vụ khách hàng (客服消息), SEO cho Mini Program (小程序搜索优化、页面收录、搜索推广、mpcrawler), và tích hợp CloudBase (wx.cloud, 腾讯云开发, 云开发) khi người dùng nói rõ dùng CloudBase. Không dùng cho frontend Web thuần, backend thuần hay chỉ thiết kế UI.

## Điểm mạnh

- Bao trọn vòng đời Mini Program: cấu trúc, config, debug, preview, upload, phát hành và SEO
- Tích hợp CloudBase (wx.cloud) theo nhu cầu, có hướng dẫn cho cả tin nhắn đẩy và客服消息

## Từ khóa

miniprogram-development, 小程序, WeChat Mini Program, CloudBase, wx.cloud

## Đầu vào

Dự án Mini Program cần làm/sửa (mã nguồn, appid, yêu cầu tính năng)

## Đầu ra

Mini Program đã phát triển/gỡ lỗi xong, sẵn sàng xem trước, kiểm thử và phát hành

## Giới hạn

Cần WeChat Developer Tools Nightly với wechatide CLI để tự động hoá local; tính năng CloudBase không dùng được trên tài khoản trial, cần tài khoản developer đã xác minh; không dùng cho frontend Web hay backend thuần
