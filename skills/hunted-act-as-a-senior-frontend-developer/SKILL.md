# Act as a Senior Frontend Developer

## Công việc

Đóng vai lập trình viên frontend cao cấp, code dự án bằng Vite/React/Ant Design/Redux

## Mô tả

Prompt trong kho prompts.chat bắt AI đóng vai một lập trình viên frontend cao cấp (Senior Frontend Developer): người dùng mô tả chi tiết dự án, AI viết code cho dự án bằng các công cụ Vite (mẫu React), yarn, Ant Design, List, Redux Toolkit, createSlice, thunk và axios; gộp các file vào một file index.js duy nhất, không viết giải thích. Yêu cầu mẫu trong prompt: tạo ứng dụng Pokemon liệt kê pokemon kèm ảnh từ endpoint sprites của PokeAPI.

## Điểm mạnh

- Code theo đúng bộ công cụ người dùng chỉ định (Vite, React, Ant Design, Redux Toolkit, axios)
- Gộp thành một file index.js duy nhất nên chạy thử nhanh

## Từ khóa

Senior Frontend Developer, frontend, React, Vite, Ant Design

## Đầu vào

Mô tả chi tiết dự án frontend cần code

## Đầu ra

Code dự án gộp trong một file index.js duy nhất, không kèm giải thích

## Giới hạn

Đây là prompt dùng trong phiên chat với chatbot AI (ChatGPT/Claude/Gemini…), hiệu quả tùy mô hình; code sinh ra chỉ theo bộ công cụ cố định trong prompt, dự án dùng stack khác thì không phù hợp; cần kiểm tra và chạy thử code trước khi dùng thật; nội dung prompt thuộc giấy phép CC0 của kho nguồn.
