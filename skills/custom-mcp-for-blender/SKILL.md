# mcp-for-blender

## Công việc

Điều khiển Blender bằng AI qua MCP

## Mô tả

Nối Blender với mọi LLM qua MCP: tạo mô hình 3D, dựng cảnh và chỉnh sửa bằng lời nhắc AI. Trước đây tên blender-mcp, gói PyPI nay là mcp-for-blender, cài đặt cũ vẫn chạy.

## Điểm mạnh

- Làm mô hình 3D chỉ bằng lời nhắc
- Nối được mọi LLM qua chuẩn MCP

## Từ khóa

mcp-for-blender, blender, mcp, 3d, mô hình 3d

## Đầu vào

Mô tả mô hình hoặc cảnh 3D muốn làm trong Blender

## Đầu ra

Mô hình/cảnh 3D trong Blender

## Giới hạn

Là tích hợp bên thứ ba, không phải của Blender; cần cài Blender và MCP server
