# file-reading

## Công việc

Đọc file người dùng tải lên đúng công cụ theo từng loại

## Mô tả

Dùng khi file đã tải lên nhưng nội dung chưa có trong ngữ cảnh, chỉ có đường dẫn. Skill này định tuyến đúng công cụ cho từng loại file: PDF, docx, xlsx, pptx, ảnh, audio, video, để đọc và trích xuất nội dung.

## Điểm mạnh

- Chọn đúng công cụ đọc cho từng loại file, khỏi đoán mò
- Đọc được cả file chưa có nội dung trong ngữ cảnh

## Từ khóa

file-reading, đọc file, tải lên, trích xuất

## Đầu vào

Đường dẫn file đã tải lên

## Đầu ra

Nội dung file đã đọc đúng định dạng

## Giới hạn

Chỉ định tuyến cách đọc, không tự sửa nội dung file
