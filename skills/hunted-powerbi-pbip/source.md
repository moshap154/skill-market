# powerbi-pbip

AI に Power BI のメジャーを足させたり、レポートを直させたりするときに、エージェントが従う手順です。対象は、Windows の Power BI Desktop で作るレポートとセマンティックモデル（データのモデル）です。

Desktop でレポートを PBIP 形式（Power BI プロジェクト）で保存すると、ふだんの .pbix の1ファイルの代わりに、テキストのファイルのフォルダーになります。レポートは PBIR という JSON、モデルは TMDL というテキストで書かれ、AI が直接読み書きできます。.pbix のレポートも、Desktop の「名前を付けて保存」で PBIP にできます。

2026年9〜10月に、Microsoft から AI 向けの道具が出そろいました。

- Desktop Bridge：開いている Desktop に、外からファイルを読み直させたり、ページのスクリーンショットを撮らせたりする仕組み
- Power BI Authoring MCP：エージェントがモデルを読み、DAX のクエリを流して値を確かめる道具（MCP は、エージェントに道具をつなぐ仕組みです）
- レポートの CLI：PBIR の JSON に誤りが無いかを検査するコマンド

ただ、道具ごとにできることが違い、組み合わせを誤ると、直した内容が Desktop に入らなかったり、Desktop の中の保存していない変更が消えたりします。たとえば、Bridge の読み直しのコマンドは、保存していない変更を確認なしに捨てます。メジャーの追加のようなモデルの変更は、このコマンドでは入りません。この Skill は、変更の種類ごとに正しい入れ方をエージェントに守らせます。

## 使い方

入れたあとは、ふだんどおりに頼みます。

> 売上のレポートに前年比のメジャーを足して、値を確かめて

エージェントは、SKILL.md に従って次のように進めます。

1. 対象が PBIP か、エージェントが Desktop と同じ Windows で動いているか、使える道具は何かを確かめる。.pbix なら、PBIP で保存し直すかを聞く
2. メジャーを TMDL のファイルに書く
3. Desktop に読み直させる。Desktop で保存していない変更があれば止まり、保存してもらうよう頼む。モデルごと読み直すスクリプト（Node.js）を同梱しています
4. DAX のクエリで値を確かめ、元のデータから出した数と並べる。Authoring MCP が無ければ、クエリを渡して Desktop で流してもらう

エージェントがクラウドなど Desktop の無い所で動いているときは、ファイルを直すところまでを行い、読み直しと確かめは手順を渡してユーザーに頼みます。

## 前提と制約

- Desktop の読み直しと撮影は Windows だけです。
- Bridge の CLI とレポートの CLI は npm のパッケージで、Node.js があれば `npx` で動きます。Authoring MCP は、使うツールの MCP の設定に足して使います。どれも無くても、エージェントは TMDL を直し、Desktop での操作をユーザーに頼んで進めます。
- Authoring MCP は、使用許諾（EULA）に同意するまで動きません。同意は使う人が条文を読んで行うもので、エージェントは代わりに同意しません。
- 日付と版の付いた動きは、作者が2026年10月に Power BI Desktop 2.158.1177.0 で確かめたものです。どの道具もプレビューを含むため、版が上がると動きが変わることがあります。Desktop の版は、「ヘルプ」の「バージョン情報」で見られます。
- Power BI サービスへの発行や、ワークスペースへの配置は扱いません。
