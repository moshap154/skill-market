# Chrome Relay

## Công việc

Điều khiển Chrome đang mở

## Mô tả

Lái phiên Chrome đang mở sẵn của bạn (kèm cookie, đăng nhập SSO, extension, localhost) qua cầu nối CLI ngay trên máy.

## Điểm mạnh

- Dùng luôn phiên đã đăng nhập — khỏi đăng nhập lại
- Không cần máy chủ trung gian, chạy ngay trên máy bạn

## Từ khóa

chrome, trình duyệt, tự động hoá, sso

## Đầu vào

Chrome đang mở + extension Chrome Relay

## Đầu ra

Thao tác tự động trên tab thật của bạn

## Giới hạn

Cần cài extension từ Chrome Web Store
