# i18n-helper

## Công việc

Hỗ trợ quốc tế hoá: quét chuỗi hardcode và sinh cấu hình i18n

## Mô tả

Skill hỗ trợ quốc tế hoá/localization (国际化/本地化) trong repo claude-code-skills-zh: quét code để tìm chuỗi văn bản viết cứng (硬编码文本) rồi sinh cấu hình i18n tương ứng, giúp dự án tách chuỗi hiển thị ra khỏi code để dịch sang nhiều ngôn ngữ.

## Điểm mạnh

- Tìm hết chuỗi hardcode rải rác trong code thay vì dò tay
- Sinh sẵn cấu hình i18n để bắt đầu dịch ngay

## Từ khóa

Danh sách chuỗi hardcode tìm được và file cấu hình i18n sinh ra
