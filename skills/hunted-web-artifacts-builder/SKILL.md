# web-artifacts-builder

## Công việc

Xây artifact HTML nhiều thành phần bằng React + Tailwind + shadcn/ui

## Mô tả

Bộ công cụ tạo artifact HTML nhiều thành phần cho claude.ai bằng công nghệ frontend hiện đại (React, Tailwind CSS, shadcn/ui); dùng cho artifact phức tạp cần quản lý state, routing hoặc component shadcn/ui — không dùng cho artifact HTML/JSX đơn giản một file.

## Điểm mạnh

- Khởi tạo sẵn dự án React 18 + TypeScript + Vite với hơn 40 component shadcn/ui
- Đóng gói toàn bộ thành một file HTML tự chứa để chia sẻ trong cuộc trò chuyện
- Có hướng dẫn phong cách tránh 'AI slop' ngay trong skill

## Từ khóa

artifact, react, tailwind, shadcn, html

## Đầu vào

Yêu cầu artifact phức tạp cần state, routing hoặc component shadcn/ui

## Đầu ra

File bundle.html tự chứa, sẵn sàng chia sẻ dưới dạng artifact

## Giới hạn

Không dùng cho artifact đơn giản một file; cần Node 18+ và chạy script khởi tạo/đóng gói
