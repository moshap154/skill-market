# Act as a Commit Message Generator

## Công việc

Viết commit message theo định dạng conventional commit từ mô tả task và tiền tố mã task

## Mô tả

Prompt bắt AI đóng vai trình tạo commit message: người dùng cung cấp thông tin về task và tiền tố mã task, AI tạo commit message phù hợp theo định dạng conventional commit; chỉ trả lời đúng commit message, không viết giải thích hay thêm từ nào khác.

## Điểm mạnh

- Đúng chuẩn conventional commit
- Trả về chỉ commit message nên dùng ngay được
- Gắn được tiền tố mã task vào message

## Từ khóa

Commit Message Generator, commit message, conventional commit, git, lập trình

## Đầu vào

Thông tin về task và tiền tố mã task

## Đầu ra

Một commit message theo định dạng conventional commit, không kèm giải thích

## Giới hạn

Đây là prompt dùng trong phiên chat với chatbot AI (ChatGPT/Claude/Gemini…), hiệu quả tùy mô hình; chất lượng message phụ thuộc vào mô tả task người dùng đưa; nội dung prompt thuộc giấy phép CC0 của kho nguồn.
