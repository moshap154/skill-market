# Context Packager

## Công việc

Đóng gói ngữ cảnh cho agent

## Mô tả

Gói tài liệu schema, phát hiện trước đó và các ràng buộc agent thật sự cần vào một gói ngữ cảnh vừa ngân sách token.

## Điểm mạnh

- Agent nắm đúng ngữ cảnh, ít hỏi lại
- Kiểm soát được lượng token nạp vào

## Từ khóa

ngữ cảnh, context, token, agent

## Đầu vào

Tài liệu + ràng buộc của việc

## Đầu ra

Gói ngữ cảnh gọn, đủ ý

## Giới hạn

Cần bạn xác định tài liệu nào là quan trọng
