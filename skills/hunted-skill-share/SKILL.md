# skill-share

## Công việc

Tạo skill Claude mới và chia sẻ tự động lên Slack

## Mô tả

Tạo skill Claude mới đúng cấu trúc (thư mục, SKILL.md, frontmatter YAML, thư mục scripts/references/assets), kiểm tra định dạng và quy ước đặt tên, đóng gói thành file zip rồi tự động đăng thông tin skill lên kênh Slack của nhóm qua Rube để mọi người cùng khám phá.

## Điểm mạnh

- Tạo đúng chuẩn cấu trúc skill, tự sinh frontmatter và kiểm tra trước khi chia sẻ
- Đóng gói thành zip sẵn sàng phân phối cho cả nhóm
- Tự động đăng lên Slack kèm tên, mô tả và link tới file skill

## Từ khóa

tạo skill, chia sẻ skill, slack, đóng gói, rube

## Đầu vào

Tên và mô tả của skill cần tạo; kênh Slack đích

## Đầu ra

Thư mục skill đúng chuẩn + file zip + thông báo đã đăng lên Slack

## Giới hạn

Cần kết nối Slack qua Rube và quyền ghi thư mục tạo skill; cần Python 3.7+ cho script tạo skill
