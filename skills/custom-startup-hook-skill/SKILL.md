# startup-hook-skill

## Công việc

Tạo hook khởi động cho phiên Claude Code cloud

## Mô tả

Tạo và phát triển hook khởi động cho phiên Claude Code cloud. Chỉ dùng khi người dùng yêu cầu hook SessionStart đưa vào repo của họ. Không dùng để dựng môi trường cloud hay repo cho phiên cloud.

## Điểm mạnh

- Hook chạy đúng lúc phiên cloud khởi động
- Gắn vào repo, dùng lại được mọi phiên

## Từ khóa

startup-hook, sessionstart, claude code cloud

## Đầu vào

Yêu cầu hook SessionStart cho repo

## Đầu ra

Hook khởi động đã tạo cho phiên cloud

## Giới hạn

Chỉ làm hook SessionStart, không dựng môi trường cloud
