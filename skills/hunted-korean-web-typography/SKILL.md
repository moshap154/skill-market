# korean-web-typography

## Công việc

Chỉnh typography tiếng Hàn trên trang web cho dễ đọc

## Mô tả

Skill tiếng Hàn (beautifulsoup.dev) chỉnh 줄바꿈 (ngắt dòng), 줄 간격 (giãn dòng), 자간 (giãn chữ), 글꼴 (font), 문단 폭 (độ rộng đoạn) của trang web sao cho hợp với tiếng Hàn.

## Điểm mạnh

- Chỉnh đúng đặc thù tiếng Hàn: ngắt dòng, giãn dòng, giãn chữ, font, độ rộng đoạn
- Tập trung vào độ dễ đọc của trang web tiếng Hàn
- Áp dụng trực tiếp lên CSS/typography của trang

## Từ khóa

korean-web-typography, 타이포그래피, typography, tiếng Hàn, web design

## Đầu vào

Trang web tiếng Hàn cần chỉnh typography

## Đầu ra

Gợi ý chỉnh ngắt dòng, giãn dòng, giãn chữ, font và độ rộng đoạn cho tiếng Hàn

## Giới hạn

Chỉ chỉnh phần trình bày chữ, không đổi nội dung hay bố cục trang; hiệu quả tùy font và trình duyệt
