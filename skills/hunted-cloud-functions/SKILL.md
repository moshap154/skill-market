# cloud-functions

## Công việc

Xây, triển khai và gỡ lỗi Cloud Functions (Event/HTTP) trên CloudBase

## Mô tả

Skill Cloud Functions trên CloudBase (cloud-functions) trong repo TencentCloudBase/skills: hướng dẫn runtime của CloudBase function để tự xây, triển khai và gỡ lỗi Event Functions hoặc HTTP Functions của chính người dùng, dùng khi cần code chạy phía server trên CloudBase, không phải khi chỉ gọi API có sẵn của nền tảng CloudBase.

## Điểm mạnh

- Hướng dẫn trọn vòng build–deploy–debug cho function của chính mình
- Phân biệt rõ function tự viết với API nền tảng có sẵn nên không dùng nhầm

## Từ khóa

cloud-functions, CloudBase, serverless, 云函数, 云开发

## Đầu vào

Yêu cầu function cần chạy trên CloudBase (loại Event hay HTTP, logic cần làm)

## Đầu ra

Cloud Function đã xây, triển khai và gỡ lỗi xong trên CloudBase

## Giới hạn

Cần môi trường CloudBase và quyền deploy; function chạy trên hạ tầng Tencent Cloud nên cần tài khoản và cấu hình đúng; chỉ cho code runtime của người dùng, không thay việc gọi API nền tảng
