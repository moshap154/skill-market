# image-prompt-builder

## Công việc

Biến ý tưởng hình ảnh thành prompt tạo ảnh tiếng Hàn và tiếng Anh

## Mô tả

Skill tiếng Hàn (beautifulsoup.dev): người dùng nói muốn vẽ hình gì, skill đổi thành prompt tạo ảnh đầy đủ 주제 (chủ đề), 스타일 (phong cách), 구도 (bố cục), 빛 (ánh sáng), 색 (màu sắc), 비율 (tỉ lệ), cả bản tiếng Hàn lẫn tiếng Anh.

## Điểm mạnh

- Một ý tưởng ra cả prompt tiếng Hàn và tiếng Anh
- Đủ 6 thành phần: chủ đề, phong cách, bố cục, ánh sáng, màu sắc, tỉ lệ
- Chỉ cần mô tả bằng lời, khỏi tự nghĩ cấu trúc prompt

## Từ khóa

image-prompt-builder, 이미지 생성 프롬프트, prompt tạo ảnh, AI image, tạo ảnh

## Đầu vào

Mô tả hình muốn tạo bằng lời

## Đầu ra

Prompt tạo ảnh tiếng Hàn và tiếng Anh gồm chủ đề, phong cách, bố cục, ánh sáng, màu sắc, tỉ lệ

## Giới hạn

Chỉ tạo prompt dạng chữ, không tự sinh ảnh; chất lượng ảnh cuối còn tùy công cụ tạo ảnh dùng kèm
