# test-driven-development

## Công việc

Viết test trước khi code (TDD)

## Mô tả

Dùng khi triển khai bất kỳ tính năng hay sửa bug nào: viết test trước, code sau.

## Điểm mạnh

- Bắt bug ngay từ lúc viết
- Code xong là có test bảo chứng

## Từ khóa

tdd, test, sửa bug, tính năng

## Đầu vào

Tính năng/bug cần làm

## Đầu ra

Test + code đạt test

## Giới hạn

Cần kỷ luật theo đúng vòng TDD
