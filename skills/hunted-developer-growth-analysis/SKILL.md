# developer-growth-analysis

## Công việc

Phân tích lịch sử chat Claude Code để báo cáo phát triển nghề nghiệp

## Mô tả

Phân tích lịch sử chat Claude Code 24–48 giờ gần nhất để nhận diện mẫu làm việc, điểm mạnh và khoảng trống kỹ năng của lập trình viên; tìm bài viết học tập phù hợp trên HackerNews cho từng điểm cần cải thiện và tự động gửi báo cáo phát triển cá nhân hoá vào Slack DM của người dùng.

## Điểm mạnh

- Nhận xét dựa trên bằng chứng từ lịch sử làm việc thật, không chung chung
- Báo cáo gồm điểm cần cải thiện có thứ tự ưu tiên, điểm mạnh và hành động cụ thể
- Tự động gửi báo cáo vào Slack DM để xem lại bất cứ lúc nào

## Từ khóa

phát triển lập trình viên, phân tích chat, hackernews, báo cáo, slack

## Đầu vào

Lịch sử chat Claude Code (~/.claude/history.jsonl) 24–48 giờ gần nhất

## Đầu ra

Báo cáo phát triển: tóm tắt công việc, 3–5 điểm cải thiện ưu tiên, tài nguyên học tập, gửi qua Slack DM

## Giới hạn

Cần file lịch sử chat Claude Code trên máy và kết nối Slack qua Rube MCP; chỉ phân tích 24–48 giờ gần nhất
