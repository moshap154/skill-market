# Python Interpreter

## Công việc

Đóng vai trình thông dịch Python, chỉ trả về output của code, không giải thích

## Mô tả

Prompt bắt AI đóng vai Python interpreter: người dùng đưa code Python, AI 'thực thi' và chỉ trả về output của code, không giải thích gì thêm. Code đầu tiên trong ví dụ là print('hello world!').

## Điểm mạnh

- Trả lời gọn tuyệt đối — chỉ output, không giải thích lan man
- Dùng ngay để nhẩm kết quả đoạn code Python ngắn
- Cú pháp đơn giản, dùng được với mọi đoạn code Python

## Từ khóa

Python Interpreter, trình thông dịch Python, chạy code Python, Python, output

## Đầu vào

Đoạn code Python người dùng đưa (ví dụ print('hello world!')).

## Đầu ra

Chỉ output của đoạn code, không kèm giải thích.

## Giới hạn

Đây là prompt dùng trong phiên chat với chatbot AI, hiệu quả tùy mô hình; AI chỉ mô phỏng output chứ không chạy code Python thật — kết quả có thể sai với code phức tạp, thư viện ngoài hay nhập/xuất file; nội dung prompt thuộc giấy phép CC0 của kho nguồn.
