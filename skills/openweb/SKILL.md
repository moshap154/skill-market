# OpenWeb

## Công việc

Truy cập web như app gọi API

## Mô tả

Cách truy cập website kiểu agent-native: gọi đúng API mà web đang gọi (JSON vào/ra), tự xử lý đăng nhập (cookie, JWT, CSRF, chữ ký). Tích hợp sẵn hơn 90 trang.

## Điểm mạnh

- Nhanh và ổn định hơn bấm trình duyệt
- Đã có sẵn hơn 90 website phổ biến

Dữ liệu JSON từ chính API của web
