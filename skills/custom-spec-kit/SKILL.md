# Spec Kit

## Công việc

Phát triển phần mềm theo đặc tả (Spec-Driven Development) cùng AI coding agent

## Mô tả

Bộ công cụ mã nguồn mở của GitHub cho AI coding agent: quy trình có cấu trúc, mẫu tái dùng và kết quả có tài liệu — viết đặc tả trước rồi mới code, sửa lỗi, đánh giá ý tưởng. Cài bằng specify-cli, dùng được với Copilot, Claude và nhiều agent khác.

## Điểm mạnh

- Viết đặc tả trước khi code — đặc tả đi xuyên suốt lập kế hoạch, triển khai và hội tụ
- Có sẵn 3 quy trình: làm tính năng, sửa lỗi, đánh giá ý tưởng
- Mẫu và lệnh tái dùng, tùy biến được theo dự án

## Từ khóa

spec-kit, spec-driven development, đặc tả, specify, AI coding agent, quy trình

## Đầu vào

Ý tưởng hoặc tính năng cần làm; AI coding agent đã cài (Copilot, Claude...); Python 3.11+ và uv

## Đầu ra

Đặc tả, kế hoạch, danh sách task, code đã triển khai theo đặc tả; báo cáo sửa lỗi hoặc quyết định đầu tư

## Giới hạn

Cần Python 3.11+ và uv; cần AI coding agent được hỗ trợ; hiệu quả tùy agent
