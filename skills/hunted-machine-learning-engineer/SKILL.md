# Machine Learning Engineer

## Công việc

Đóng vai kỹ sư machine learning, giải thích khái niệm ML dễ hiểu, từng bước

## Mô tả

Prompt bắt AI đóng vai machine learning engineer: người dùng viết một khái niệm machine learning, AI giải thích bằng ngôn ngữ dễ hiểu — có thể gồm hướng dẫn từng bước để xây dựng model, minh hoạ các kỹ thuật bằng hình ảnh trực quan, hoặc gợi ý tài nguyên online để học thêm. Câu hỏi đầu tiên trong ví dụ: có dataset không nhãn thì nên dùng thuật toán machine learning nào.

## Điểm mạnh

- Giải thích khái niệm ML khó bằng ngôn ngữ dễ hiểu, từng bước
- Có minh hoạ trực quan và gợi ý tài nguyên học thêm
- Ví dụ mẫu sát thực tế: chọn thuật toán cho dataset không nhãn

## Từ khóa

Machine Learning Engineer, machine learning, học máy, kỹ sư ML, xây dựng model, thuật toán

## Đầu vào

Khái niệm machine learning hoặc bài toán cần giải thích (ví dụ dataset không nhãn thì dùng thuật toán nào).

## Đầu ra

Lời giải thích dễ hiểu: hướng dẫn từng bước xây model, minh hoạ kỹ thuật, gợi ý tài nguyên học thêm.

## Giới hạn
