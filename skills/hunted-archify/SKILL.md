# archify

## Công việc

Biến ý tưởng, kế hoạch hoặc codebase thành sơ đồ tương tác

## Mô tả

Biến ý tưởng, câu hỏi, kế hoạch hoặc cả một codebase thành sơ đồ tương tác dạng HTML tự chứa: sơ đồ kiến trúc, luồng, sequence, sơ đồ hệ thống. Có thể bắt đầu chỉ bằng mô tả, không cần repo; hoặc đọc repo để vẽ sơ đồ kiến trúc có dẫn nguồn tới commit cụ thể. Ngoài sơ đồ còn làm được trang giải thích một câu hỏi trong một trang (explainer) với kết luận trước, từng panel kèm bảng, bước và biểu đồ. Hỗ trợ Claude Code, Codex, Cursor, OpenCode; giấy phép Apache 2.0.

## Điểm mạnh

- Không cần repo vẫn vẽ được sơ đồ từ mô tả; có repo thì sơ đồ gắn nguồn tới commit cụ thể, dễ kiểm chứng
- Kết quả là một file HTML tự chứa, tải về mở bằng trình duyệt là xem được, xuất PNG/WebP/JPG hoặc in PDF
- Tinh chỉnh bằng chat: thêm bước, đổi theme sáng/tối, làm nổi bật một luồng

## Từ khóa

sơ đồ, kiến trúc, diagram, trực quan hoá, html

## Đầu vào

Ý tưởng, câu hỏi hoặc kế hoạch bằng lời; hoặc đường dẫn tới codebase cần vẽ sơ đồ

## Đầu ra

File HTML sơ đồ tương tác (kèm bản xuất PNG/WebP/JPG/PDF); trang explainer trả lời một câu hỏi

## Giới hạn

Sơ đồ vẽ từ mô tả không có nguồn kiểm chứng; cần kiểm tra lại khi dùng sơ đồ kiến trúc cho hệ thống thật
