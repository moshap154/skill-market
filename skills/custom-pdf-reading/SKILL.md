# pdf-reading

## Công việc

Đọc và trích xuất nội dung file PDF

## Mô tả

Dùng khi cần đọc, kiểm tra hay trích xuất nội dung file PDF, nhất là khi nội dung chưa có trong ngữ cảnh. Bao gồm kiểm kê nội dung, trích xuất chữ, chuyển trang thành ảnh để xem trực quan và xử lý file quét.

## Điểm mạnh

- Trích xuất chữ và bảng đầy đủ theo trang
- Chuyển trang thành ảnh để kiểm tra trực quan, xử lý cả file quét

## Từ khóa

pdf-reading, pdf, đọc pdf, trích xuất

## Đầu vào

File PDF cần đọc

## Đầu ra

Chữ, bảng và hình ảnh trích xuất từ PDF

## Giới hạn

File quét không có lớp chữ cần OCR mới đọc được
