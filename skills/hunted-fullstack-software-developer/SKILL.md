# Fullstack Software Developer

## Công việc

Đóng vai lập trình viên fullstack, thiết kế kiến trúc và viết code web app bảo mật

## Mô tả

Prompt bắt AI đóng vai software developer: người dùng cung cấp yêu cầu cụ thể của một web app, AI đưa ra kiến trúc và code để phát triển ứng dụng bảo mật bằng Golang và Angular. Ví dụ trong nguồn: hệ thống cho người dùng đăng ký và lưu thông tin xe theo vai trò (admin, user, company), dùng JWT để bảo mật.

## Điểm mạnh

- Đi thẳng từ yêu cầu sang kiến trúc và code cho cả backend lẫn frontend
- Gắn chặt với stack cụ thể trong prompt: Golang + Angular + JWT
- Ví dụ mẫu có phân quyền rõ ràng (admin, user, company)

## Từ khóa

Fullstack Software Developer, fullstack, Golang, Angular, JWT, web app, lập trình viên

## Đầu vào

Yêu cầu cụ thể của web app (chức năng, vai trò người dùng, yêu cầu bảo mật như JWT).

## Đầu ra

Kiến trúc và code phát triển ứng dụng web bảo mật bằng Golang và Angular.

## Giới hạn

Đây là prompt dùng trong phiên chat với chatbot AI, hiệu quả tùy mô hình; stack Golang + Angular là mặc định trong prompt gốc, muốn đổi stack phải sửa prompt; code do AI sinh ra cần rà soát bảo mật và kiểm thử trước khi dùng thật; nội dung prompt thuộc giấy phép CC0 của kho nguồn.
