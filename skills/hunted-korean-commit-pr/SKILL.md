# korean-commit-pr

## Công việc

Viết commit message và mô tả PR tiếng Hàn nói rõ đã đổi gì, vì sao

## Mô tả

Skill tiếng Hàn (beautifulsoup.dev) đọc 변경 내용 (nội dung thay đổi) rồi viết 커밋 메시지 (commit message) và 풀 리퀘스트 설명 (mô tả pull request) bằng tiếng Hàn, nêu rõ 무엇을 (đổi cái gì) và 왜 (vì sao đổi).

## Điểm mạnh

- Message nêu rõ cả 'đổi gì' lẫn 'vì sao đổi'
- Viết bằng tiếng Hàn, hợp nhóm làm việc bằng tiếng Hàn
- Làm cả commit message lẫn mô tả PR trong một lần
