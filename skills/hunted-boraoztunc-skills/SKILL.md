# Boraoztunc Skills

## Công việc

Kho skill copywriting, SEO, thiết kế và motion cho Claude Code

## Mô tả

Kho skill Claude Code về copywriting, quảng cáo, SEO, thiết kế và hơn thế: cụm viết & copy (Ogilvy, copywriting, copy-editing, stop-slop), thiết kế & frontend (frontend-design, web design guidelines, Vercel React best practices, app store screenshots), bộ motion của Emil Kowalski (animate, choreograph, gestures, hiệu năng animation...), các quy tắc giao diện better-* (UI, typography, màu, accessibility, layout, viết), phong cách trực quan (visual style presets, Tailwind v4, shadows, glass, skeuomorphic...), loại trang & SEO (landing page, pricing page, programmatic SEO, seo-audit, schema markup) và video HyperFrames. Mỗi skill là một file markdown tự chứa, gọi bằng slash command. Giấy phép Apache-2.0 (một số skill vendored giữ giấy phép gốc).

## Điểm mạnh

- Nhiều skill là bản audit/chọn lọc từ các bộ nổi tiếng (Emil Kowalski, MengTo, jakubkrehel) kèm ghi chú nguồn gốc rõ ràng
