# TrendRadar

## Công việc

Giám sát hotspot đa nền tảng bằng AI, lọc theo từ khoá và đẩy về WeChat/Feishu/DingTalk

## Mô tả

Trợ lý giám sát dư luận và hotspot bằng AI (hơn 63.000 star): gom hotspot nhiều nền tảng + RSS, lọc chính xác theo từ khoá, AI sàng lọc tin, dịch đa ngôn ngữ, phân tích và gửi简报 về điện thoại; đẩy qua WeChat (cá nhân/doanh nghiệp), Feishu, DingTalk, Telegram, email, ntfy, Bark, Slack; hỗ trợ MCP để hỏi đáp phân tích bằng ngôn ngữ tự nhiên; triển khai nhanh bằng Docker hoặc GitHub Actions, dữ liệu tự giữ ở local/cloud. Giấy phép GPL-3.0.

## Điểm mạnh

- Gom nhiều nền tảng + RSS rồi lọc AI theo từ khoá, giảm nhiễu thông tin
- Đẩy简报 AI thẳng về WeChat/Feishu/DingTalk/Telegram, xem được trên điện thoại
- Có MCP server để phân tích xu hướng bằng hội thoại, triển khai 30 giây bằng Docker

## Từ khóa

TrendRadar, 舆情监控, 热点, giám sát dư luận, RSS, 热点监控, AI简报

## Đầu vào

Từ khoá quan tâm, nền tảng cần theo dõi, kênh nhận đẩy (WeChat/Feishu/DingTalk...)

## Đầu ra

Bản tin hotspot đã lọc AI, phân tích xu hướng, gửi đúng kênh đã chọn

## Giới hạn

Cần tự triển khai (Docker/GitHub Actions/local) và cấu hình key AI nếu dùng phân tích AI; dữ liệu hotspot lấy qua API bên thứ ba (newsnow) nên phụ thuộc nguồn đó; chỉ lọc và tóm tắt tin, không tự xác minh tính thật của tin.
