# interactive-web-slides

## Công việc

Chuyển tài liệu/Markdown thành slide web HTML tương tác

## Mô tả

Chuyển file Markdown (.md), tài liệu PDF, DOCX, Google Docs, TXT hoặc ghi chú thô thành một deck slide web HTML tương tác, tự chứa trong một file duy nhất, phong cách dark-mode lưới tối: định tuyến bằng hash URL (#s1, #s2), sidebar dàn ý thu gọn, thanh điều khiển nổi, chuyển ngôn ngữ VI/EN và hiệu ứng xuất hiện theo từng bước.

## Điểm mạnh

- Ra một file HTML duy nhất, không cần build và tránh CDN nặng nên chạy nhanh, gọn, dùng offline được
- Có sẵn template deck-template.html kèm định tuyến hash, sidebar dàn ý, chuyển ngôn ngữ VI/EN và hiệu ứng theo từng bước
- Chia nội dung một ý/slide với bố cục so sánh 3 cột, quy trình theo lượt và checklist/KPI, kèm bước kiểm tra trước khi giao file

## Từ khóa

slide web, HTML, Markdown, thuyết trình, dark mode

## Đầu vào

File .md, PDF, DOCX, Google Docs, TXT hoặc ghi chú/outline thô cần chuyển thành slide

## Đầu ra

Một file HTML slide duy nhất, đặt tên theo dạng [TenFile]_v1_[MMYYYY].html, đã kiểm tra id slide tuần tự, metadata VI và không còn placeholder

## Giới hạn

Mỗi slide tối đa 3 cột hoặc 5 bullet ngắn để không tràn màn hình laptop; nội dung thô hoặc mơ hồ cần trình slide map cho người dùng xác nhận trước; deck rất lớn (20+ slide) chỉ tiếng Việt thì ẩn nút chuyển ngữ; không bịa số liệu chưa đo, phải ghi rõ là ước tính
