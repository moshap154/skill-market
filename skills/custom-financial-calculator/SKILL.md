# financial-calculator

Chạy tính toán tài chính và so sánh kịch bản: ước tính thuế, so sánh khoản vay, dự báo hưu trí, thuê với mua, kịch bản đầu tư. Chỉ tính toán, không cần tài khoản hay đăng nhập.

## Điểm mạnh

- So sánh nhiều kịch bản cùng lúc
- Chỉ tính toán, không cần đăng nhập tài khoản
