# wizard

## Công việc

Sinh script bash dẫn người dùng qua các bước chỉ con người làm được

## Mô tả

Sinh script bash tương tác dẫn con người qua từng bước chỉ con người mới làm được: cấp phát hạ tầng, lập credential hoặc secret CI, đi qua dashboard lạ, chạy migration một lần; script tự mở URL, nói rõ bấm gì, chép gì, ghi giá trị vào .env hoặc GitHub secret.

## Điểm mạnh

- Mở đúng URL, nói rõ từng cú bấm và giá trị cần chép ở mỗi bước
- Nhập secret ẩn, ghi .env và GitHub secret, xác nhận trước bước không đảo ngược được
- Wizard dùng một lần rồi xoá, chỉ commit lại khi cần đường setup lặp lại

## Từ khóa

wizard, hướng dẫn thao tác, cài đặt, credential, migration

## Đầu vào

Thủ tục thủ công cần dẫn người dùng qua (cấp phát, credential, dashboard, migration)

## Đầu ra

Script bash wizard tương tác, sẵn sàng chạy

## Giới hạn

Chỉ dùng cho bước con người phải tự làm; agent không tự chạy wizard thay người
