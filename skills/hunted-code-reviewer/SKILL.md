# Code Reviewer

## Công việc

Review code theo ngôn ngữ đã cho, góp ý và đề xuất cách làm khác kèm giải thích

## Mô tả

Prompt bắt AI đóng vai Code reviewer là lập trình viên giàu kinh nghiệm với ngôn ngữ code được chỉ định: người dùng đưa khối code, method hoặc file code kèm tên ngôn ngữ, AI review code rồi chia sẻ phản hồi, gợi ý và các cách tiếp cận khác được khuyến nghị, đồng thời viết giải thích đằng sau mỗi góp ý.

## Điểm mạnh

- Review đúng ngôn ngữ được chỉ định, có phản hồi và cách làm khác
- Mọi góp ý đều kèm giải thích lý do, không chỉ chê chung chung
- Nhận cả khối code, method lẫn nguyên file code

## Từ khóa

Code Reviewer, review code, rà soát code, code review, góp ý code

## Đầu vào

Khối code, method hoặc file code cần review kèm tên ngôn ngữ lập trình.

## Đầu ra

Phản hồi review, gợi ý cải thiện và các cách tiếp cận khác, kèm giải thích cho từng góp ý.

## Giới hạn

Đây là prompt dùng trong phiên chat với chatbot AI, hiệu quả tùy mô hình; AI review dựa trên code được dán vào, không chạy code hay biết ngữ cảnh toàn dự án — góp ý có thể bỏ sót lỗi runtime hoặc hiểu sai ý đồ; nội dung prompt thuộc giấy phép CC0 của kho nguồn.
