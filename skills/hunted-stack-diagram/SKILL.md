# stack-diagram

## Công việc

Vẽ sơ đồ kiến trúc hệ thống kèm logo chính thức

## Mô tả

Mô tả stack công nghệ bằng một câu và nhận sơ đồ kiến trúc dùng logo chính thức của từng thành phần; icon AWS, Google Cloud và Azure lấy từ gói chính thức của từng hãng; kết quả là một file HTML tự chứa duy nhất, có cả giao diện sáng và tối.

## Điểm mạnh

- Một câu mô tả ra ngay sơ đồ kiến trúc
- Dùng logo chính thức của AWS, Google Cloud, Azure
- Xuất một file HTML tự chứa, có cả giao diện sáng và tối

## Từ khóa

sơ đồ kiến trúc, stack công nghệ, aws, azure, google cloud

## Đầu vào

Mô tả stack công nghệ bằng một câu

## Đầu ra

File HTML tự chứa chứa sơ đồ kiến trúc (sáng/tối)

## Giới hạn

Chỉ vẽ sơ đồ theo mô tả bạn đưa; không kiểm chứng kiến trúc thật của hệ thống
