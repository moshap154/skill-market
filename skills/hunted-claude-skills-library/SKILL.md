# Claude Skills Library

## Công việc

Thư viện 230 skill cho bán hàng, marketing, thiết kế, kỹ thuật và đời sống

## Mô tả

Thư viện 230 skill Claude Code sẵn sàng dùng cho bán hàng, marketing, thiết kế, kỹ thuật và kiến trúc AI agent, do OneWave AI xây dựng: ba trụ cột là kinh doanh (bán hàng, marketing, tư vấn, vận hành), đời sống (tài chính cá nhân, du lịch, thể dục, tìm việc) và code (kỹ thuật, thiết kế, kiến trúc agent). Nổi bật: agent-army (triển khai 3–50+ agent song song để refactor lớn, audit toàn site, migration), brand-voice-analyzer (đọc copy sẵn có để lập hồ sơ giọng văn), landing-page-copywriter, cold-email-sequence-generator, review-response-writer và compliance-checker. Mỗi skill là một file đơn, không phụ thuộc ngoài; cài một skill hoặc clone cả thư viện. MIT.

## Điểm mạnh

- 230 skill phủ cả công việc kinh doanh lẫn đời sống, mỗi skill một việc với deliverable rõ ràng nên dễ gắn vào quy trình tự động
- Có agent-army để chạy đội agent song song cho việc lớn (refactor, audit, migration)
- brand-voice-analyzer lập hồ sơ giọng văn trước khi các skill viết khác chạy theo

## Từ khóa

bán hàng, marketing, kỹ thuật, thiết kế, agent, tự động hoá

## Đầu vào

Nhiệm vụ cụ thể theo từng skill (brief bán hàng, bản nháp copy, codebase cần audit...)

## Đầu ra

Deliverable theo từng skill: email, trang bán, báo cáo, kế hoạch, phân tích...

## Giới hạn

Theo chính bài đánh giá được trích dẫn, các skill viết nông hơn các bộ chuyên sâu; compliance-checker là kiểm tra tuân thủ kinh doanh chung, không phải kiểm tra riêng cho nền tảng quảng cáo Meta
