# obsidian-skills

## Công việc

Dạy agent làm việc trong vault Obsidian qua CLI và định dạng mở

## Mô tả

Bộ skill chính thức của Obsidian, dạy agent dùng Obsidian CLI và các định dạng mở của Obsidian: Markdown có wikilink, Bases (.base) với khung nhìn/bộ lọc/công thức, JSON Canvas (.canvas), đồng bộ và xuất bản vault từ dòng lệnh bằng Obsidian Headless mà không cần mở app desktop, trích xuất markdown sạch từ trang web bằng Defuddle, và render template Markdown từ dữ liệu JSON/CSV bằng Knap. Cài qua marketplace của Claude Code, Codex, Cursor hoặc npx skills; giấy phép MIT.

## Điểm mạnh

- Skill chính thức từ đội Obsidian, theo chuẩn Agent Skills nên dùng được trên nhiều agent
- Làm việc trực tiếp trong vault thật qua CLI thay vì chỉ đọc file rời
- Có cả trích xuất web sạch (Defuddle) và render template hàng loạt từ dữ liệu (Knap)

## Từ khóa

obsidian, ghi chú, markdown, vault, bases, canvas

## Đầu vào

Đường dẫn vault Obsidian; yêu cầu tạo/sửa ghi chú, Bases, Canvas hoặc đồng bộ vault

## Đầu ra

Ghi chú Markdown, file .base, file .canvas đã tạo/sửa; vault đã đồng bộ/xuất bản

## Giới hạn

Một số thao tác cần cài Obsidian CLI/Headless; cần quyền ghi vào vault
