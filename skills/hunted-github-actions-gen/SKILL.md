# github-actions-gen

## Công việc

Sinh workflow GitHub Actions an toàn, kiểm chứng được từ dự án thật

## Mô tả

Skill sinh workflow GitHub Actions (CI/CD) trong repo claude-code-skills-zh: phân tích dự án thật rồi sinh file workflow GitHub Actions an toàn và có thể kiểm chứng (安全、可验证), dùng khi cần tự động build, test hoặc deploy trên GitHub.

## Điểm mạnh

- Workflow sinh theo đúng dự án thật, không phải mẫu chung chung
- Nhấn mạnh an toàn và kiểm chứng được trước khi đưa vào CI/CD

## Từ khóa

github-actions-gen, GitHub Actions, CI/CD, workflow, 自动化部署

## Đầu vào

Dự án cần CI/CD (ngôn ngữ, cách build/test/deploy hiện tại)

## Đầu ra

File workflow GitHub Actions (.yml) cho dự án

## Giới hạn

Workflow cần xem lại và chạy thử trên nhánh test trước khi dùng cho nhánh chính; sai sót trong workflow có thể làm lộ secret hoặc deploy nhầm
