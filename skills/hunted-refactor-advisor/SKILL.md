# refactor-advisor

## Công việc

Tìm mùi code xấu và đề xuất phương án refactor thực thi được

## Mô tả

Skill gốc của kho Claude Code Skills 中文精选集: rà soát code để nhận diện các 'mùi' xấu (bad smells) rồi đưa ra đề xuất refactor cụ thể, có thể thực thi từng bước. Một trong 5 skill gốc được kho khuyên cài đầu tiên.

## Điểm mạnh

- Chỉ ra đúng vị trí mùi code thay vì nhận xét chung chung
- Đề xuất refactor kèm phương án thực thi cụ thể
- Cài đặt bằng cách copy thư mục, dùng được trên Claude Code và CLI tương thích

## Từ khóa

refactor-advisor, 重构, refactor, tái cấu trúc, bad smell, mùi code

## Đầu vào

Code hoặc module cần rà soát để refactor

## Đầu ra

Danh sách mùi code kèm đề xuất refactor từng bước

## Giới hạn

Chỉ tư vấn, không tự sửa code khi chưa được phép; đề xuất cần người review trước khi áp dụng vào code đang chạy; cần công cụ hỗ trợ SKILL.md.
