# code-review-ko

## Công việc

Review code, diff hoặc PR và báo cáo bằng tiếng Hàn theo mức độ

## Mô tả

Skill tiếng Hàn (beautifulsoup.dev) 검토 (review) 코드, diff, 풀 리퀘스트: trước hết nắm 목적 (mục đích) của thay đổi, đọc cả nơi gọi và nơi được gọi chứ không chỉ nhìn diff, rồi xếp vấn đề theo 무게 (mức nặng nhẹ): 고쳐야 함 (phải sửa: bug, 보안 취약점/lỗ hổng bảo mật, 데이터 손실/mất dữ liệu, 경쟁 상태/race condition, thay đổi khó 되돌리기), 고치면 좋음 (nên sửa: khó đọc, 중복, thiếu test, tên gây hiểu lầm), 취향 (sở thích: phong cách, cách khác cũng được). Mỗi 지적 (nhận xét) gồm 파일과 줄 (file và dòng), vấn đề một câu, tình huống/đầu vào gây ra vấn đề, và code sửa (chỉ phần đổi). Báo cáo bằng tiếng Hàn, giữ nguyên code và tên định danh; vấn đề cũ ngoài phạm vi thay đổi thì gom riêng; không chắc thì không khẳng định; luôn ghi ít nhất một điểm tốt. Trả về 판단 (kết luận: 합쳐도 됨/gộp được, 고친 뒤 합침/sửa rồi gộp, 다시 설계/thiết kế lại), danh sách nhận xét theo mức, test còn thiếu và điểm ngoài phạm vi.

## Điểm mạnh

- Xếp vấn đề theo 3 mức: phải sửa, nên sửa, sở thích — ưu tiên rõ ràng
- Đọc cả ngữ cảnh gọi hàm chứ không chỉ nhìn diff
- Mỗi nhận xét kèm file:dòng, tình huống gây lỗi và code sửa cụ thể

## Từ khóa

code-review-ko, 코드 리뷰, review code, pull request, diff

## Đầu vào

Code, diff hoặc pull request cần review, kèm mục đích của thay đổi

## Đầu ra

Kết luận (gộp được / sửa rồi gộp / thiết kế lại), danh sách nhận xét theo mức kèm file:dòng và code sửa, test còn thiếu

## Giới hạn

Chỉ review và báo cáo, không tự sửa code; nhận xét không chắc chắn được hạ xuống '확인 필요' (cần xác nhận) thay vì khẳng định
