# agent-instructions

## Công việc

Dọn và viết file chỉ dẫn cho AI agent (AGENTS.md, CLAUDE.md)

## Mô tả

Skill tiếng Nhật của itoken-lab-jp hướng dẫn đặt, thêm và rà soát file chỉ dẫn agent đọc mỗi lần làm việc (AGENTS.md, CLAUDE.md, .cursor/rules): chỉ viết thứ không suy ra được từ code, gom quy tắc trùng về một file gốc duy nhất, đối chiếu lệnh và đường dẫn với thực tế, đo lượng chữ phải đọc trước và sau khi dọn, giữ quy tắc từ sự cố kèm lý do, kiểm chứng bằng phiên mới.

## Điểm mạnh

- Đo lượng chỉ dẫn phải đọc nên thấy hiệu quả dọn dẹp bằng con số
- Một file gốc duy nhất, hết lệch nhau giữa các công cụ
- Có bước kiểm chứng ở phiên mới

## Từ khóa
