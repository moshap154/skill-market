# blender-headless

## Công việc

Chạy Blender không giao diện (headless, bpy) để render animation có vật lý

## Mô tả

Skill tiếng Nhật của tomotto1296 (repo ai-animation-skills) chạy Blender ở chế độ headless bằng bpy: dùng launcher ghi file “done” để báo xong, đặt ngân sách mẫu/thời gian (sample/time budgets), và dùng physics probes cùng hiệu ứng chất lỏng/vải (fluids/cloth). Thân skill viết bằng tiếng Nhật (phần description bằng tiếng Anh); cần Blender 5.x, đặt biến BLENDER_EXE hoặc dùng bản Microsoft Store.

## Điểm mạnh

- Chạy Blender headless bằng bpy nên tự động hóa được việc render
- Launcher ghi file “done” để biết chắc lần render đã xong
- Có ngân sách mẫu/thời gian và physics probes cho chất lỏng/vải

## Từ khóa

blender-headless, Blender, bpy, render, 3D, animation

## Đầu vào

Scene/nhiệm vụ Blender cần render (kèm yêu cầu vật lý chất lỏng/vải nếu có)

## Đầu ra

Animation đã render bằng Blender headless

## Giới hạn

Cần Blender 5.x và đặt BLENDER_EXE (hoặc bản Microsoft Store); script viết trên Windows 11, chưa chạy thử trên hệ điều hành khác.
