# vibe-coding-prd

## Công việc

Gom yêu cầu rời rạc thành PRD tiếng Trung để giao cho coding agent

## Mô tả

Skill viết PRD cho vibe coding (vibe-coding-prd) trong repo YiShu5/claude-skills: gom yêu cầu của người dùng, PRD thô, phân tích đối thủ hoặc ý tưởng rời rạc thành một bản PRD tiếng Trung gọn, trực tiếp đưa cho Claude Code, Codex hoặc coding agent khác thực thi (coding-agent-ready PRD). Kích hoạt khi người dùng nhờ viết PRD để vibe coding, hoặc muốn trích thông tin cần cho việc triển khai từ tài liệu nghiệp vụ/sản phẩm.

## Điểm mạnh

- Biến yêu cầu mơ hồ, rời rạc thành PRD gọn, đủ ý để coding agent làm ngay
- Giữ nguyên thông tin nghiệp vụ/sản phẩm cần thiết, bỏ phần thừa

## Từ khóa

vibe-coding-prd, PRD, vibe coding, 需求文档, coding agent

## Đầu vào

Yêu cầu, PRD thô, phân tích đối thủ hoặc ghi chú ý tưởng rời rạc

## Đầu ra

Bản PRD tiếng Trung (Markdown) gọn, sẵn sàng giao cho coding agent

## Giới hạn

PRD chỉ đúng tới mức tài liệu đầu vào là đúng; yêu cầu mơ hồ thì PRD cũng mơ hồ theo; cần người duyệt PRD trước khi giao agent code
