# huggingface-spaces

## Công việc

Xây, triển khai và bảo trì ứng dụng trên Hugging Face Spaces

## Mô tả

Skill chính thức của Hugging Face: xây, triển khai và bảo trì ứng dụng trên Hugging Face Spaces — Gradio/Docker/Static SDK, ZeroGPU và phần cứng chuyên dụng, load model, debug, bucket, inference provider, community grant. Dùng khi người dùng muốn tạo hoặc host app trên Hugging Face, port code lên ZeroGPU, sửa Space không build/chạy được, hoặc làm việc với hf spaces …, @spaces.GPU, frontmatter README của Space, hay gói spaces trong Python. Hiện có hơn 1 triệu Space, mỗi Space là một git repo. Chuẩn bị: kiểm tra CLI hf đã cài, đăng nhập bằng hf auth login (OAuth, không cần token) hoặc token write-scoped; lưu ý cờ canPay/isPro — tài khoản miễn phí chỉ host Static Space và tối đa 2 Space ZeroGPU. Repo gốc giấy phép Apache-2.0.

## Điểm mạnh

- Bao trọn vòng đời Space: tạo, build, debug, bảo trì, bucket, inference provider
- Hướng dẫn rõ giới hạn tài khoản miễn phí (Static + tối đa 2 ZeroGPU)
- Đăng nhập OAuth không cần token, mỗi Space là git repo nên quản lý như code

## Từ khóa

Hugging Face Spaces, Gradio, ZeroGPU, deploy app, Docker, hosting

## Đầu vào

Ứng dụng cần host hoặc Space cần sửa, kèm SDK (Gradio/Docker/Static) và phần cứng mong muốn

## Đầu ra

Space đã tạo/triển khai/sửa xong trên Hugging Face, chạy được trên trình duyệt

## Giới hạn

Thuộc hệ sinh thái Hugging Face; cần tài khoản Hub và đăng nhập hf; tài khoản miễn phí chỉ host Static Space và tối đa 2 Space ZeroGPU; phần cứng trả phí cần Pro/thanh toán. Giấy phép Apache-2.0.
