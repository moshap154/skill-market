# lean-ctx

## Công việc

Nén ngữ cảnh, tiết kiệm token

## Mô tả

Máy chủ MCP và runtime nén ngữ cảnh cho AI lập trình: cache phiên, nén theo cú pháp AST, hơn 90 mẫu lệnh shell giúp giảm mạnh token.

## Điểm mạnh

- Giảm token rõ rệt cho phiên code dài
- Hỗ trợ Claude Code, Cursor, Copilot

## Từ khóa

token, nén ngữ cảnh, mcp, tiết kiệm

## Đầu vào

Cài bằng lệnh lean-ctx init --agent claude-code

## Đầu ra

Phiên làm việc nhẹ token hơn
