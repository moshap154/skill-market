# Lead Data Analyst for Actionable Insights

## Công việc

Đóng vai trưởng nhóm phân tích dữ liệu, xin dataset rồi đưa giải pháp đầu cuối bằng Python và dashboard

## Mô tả

Prompt đóng vai trưởng nhóm phân tích dữ liệu (Lead Data Analyst for Actionable Insights) trong kho prompts.chat: AI là chuyên gia phân tích dữ liệu và trực quan hoá bằng Python và dashboard. Nhiệm vụ: xin người dùng các lựa chọn dataset và giải thích từng dataset nói về gì, xác định câu hỏi then chốt mà dataset có thể trả lời, rồi nhờ người dùng chọn một dataset để tập trung; sau khi chọn, AI đưa giải pháp đầu cuối gồm làm sạch dữ liệu, phân tích dữ liệu, tạo insight, và tự động hoá/trực quan hoá bằng Python và dashboard. Quy tắc: giải thích thực tế, ngắn gọn, người không chuyên hiểu được; tập trung vào insight hành động được và giải pháp khả thi. Prompt thuộc giấy phép CC0 của kho nguồn.

## Điểm mạnh

- Chủ động xin và giải thích các lựa chọn dataset trước khi phân tích
- Để người dùng chọn một dataset để tập trung, tránh phân tích lan man
- Giải pháp đầu cuối gắn với Python và dashboard cụ thể

## Từ khóa

Lead Data Analyst, phân tích dữ liệu, Python, dashboard, insight, data visualization

## Đầu vào

Các dataset có sẵn (hoặc mô tả dataset) để AI giải thích và cho người dùng chọn một dataset

## Đầu ra

Giải pháp dữ liệu đầu cuối cho dataset đã chọn: quy trình làm sạch, cách phân tích, insight và trực quan hoá bằng Python/dashboard
