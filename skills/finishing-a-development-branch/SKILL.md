# finishing-a-development-branch

## Công việc

Chốt nhánh code khi làm xong

## Mô tả

Hướng dẫn hoàn tất một nhánh phát triển: trình bày rõ các lựa chọn (merge, PR, dọn dẹp) và thực hiện theo lựa chọn của bạn.

## Điểm mạnh

- Chốt việc gọn, không để nhánh treo
- Luôn trình bày lựa chọn trước khi merge/xoá

## Từ khóa

git, branch, merge, pull request

## Đầu vào

Nhánh code đã làm xong

## Đầu ra

Nhánh được merge/đóng đúng quy trình

## Giới hạn

Theo quy ước repo của bạn
