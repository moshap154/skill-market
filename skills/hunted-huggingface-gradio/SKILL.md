# huggingface-gradio

## Công việc

Xây giao diện web và demo ML bằng Gradio trong Python

## Mô tả

Skill chính thức của Hugging Face: xây giao diện web và demo ML bằng Gradio trong Python. Dùng khi tạo, sửa, debug hoặc trả lời câu hỏi về Gradio và khả năng của nó: component, event listener, layout. Skill bao phủ API cốt lõi, các pattern và ví dụ minh họa, kèm tài liệu tham khảo về chữ ký API của các component thường dùng, event listener của từng component, cùng các hướng dẫn chi tiết (Quickstart, Interface class, Blocks và Event Listeners, kiểm soát layout, tính năng Blocks nâng cao, CSS/JS tùy chỉnh). Gradio là thư viện Python để xây giao diện web tương tác và demo ML. Repo gốc giấy phép Apache-2.0.

## Điểm mạnh

- Bao phủ toàn bộ API cốt lõi của Gradio: component, event, layout
- Có ví dụ minh họa và chữ ký API sẵn để tra cứu nhanh
- Kèm hướng dẫn chính thức từ Quickstart tới CSS/JS tùy chỉnh

## Từ khóa

Gradio, Python, web UI, ML demo, Interface, Blocks

## Đầu vào

Yêu cầu giao diện/demo cần xây hoặc code Gradio cần sửa/debug

## Đầu ra

Code Gradio hoàn chỉnh hoặc hướng dẫn sửa lỗi kèm giải thích API liên quan

## Giới hạn

Thuộc hệ sinh thái Hugging Face; chỉ bao phủ Gradio (Python), không thay thế việc đọc docs Gradio mới nhất khi API thay đổi. Giấy phép Apache-2.0.
