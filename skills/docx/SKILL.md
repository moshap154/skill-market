# docx

## Công việc

Tạo & sửa file Word

## Mô tả

Tạo, chỉnh sửa và phân tích tài liệu Word, gồm theo dõi thay đổi (track changes), nhận xét và định dạng chuẩn.

## Điểm mạnh

- Giữ nguyên định dạng và track changes như Word thật
- Thêm nhận xét, sửa bài ngay trong file .docx

## Từ khóa

word, docx, văn bản, soạn thảo, hợp đồng

## Đầu vào

File .docx hoặc nội dung cần soạn

## Đầu ra

File Word hoàn chỉnh, đúng định dạng

## Giới hạn

Macro và tính năng Word nâng cao không hỗ trợ
