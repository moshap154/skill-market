Skill tự cải thiện cho agent (self-improving-agent) trong repo YiShu5/claude-skills: ghi những kinh nghiệm, lỗi và cách sửa có thể dùng lại vào thư mục .learnings/ ở local, để agent học từ lần làm trước thay vì lặp lại lỗi cũ. README của repo xếp skill này vào nhóm 经验沉淀 (tích lũy kinh nghiệm).
