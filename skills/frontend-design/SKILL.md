# Frontend Design

## Công việc

Thiết kế giao diện web có cá tính

## Mô tả

Tạo giao diện đạt chuẩn sản phẩm thật, tránh kiểu 'AI slop' chung chung: typography mạnh, màu sắc nhất quán, chuyển động chính xác — cài đặt bằng code thật.

## Điểm mạnh

- Giao diện có cá tính, không generic
- Ra code thật chạy được, không phải mockup
