# logo-design

## Công việc

Thiết kế logo từ brief tới file SVG

## Mô tả

Biến Claude thành nhà thiết kế nhận diện có kỷ luật: từ brief tới file SVG dùng được trong sản xuất; kèm thư viện tham khảo hơn 1.400 logo thật và công cụ Python kiểm tra logo ở cỡ 16px, một màu và bản đảo màu; đưa ra ba concept rồi dừng lại chờ bạn chọn một.

## Điểm mạnh

- Đi trọn từ brief tới file SVG sản xuất
- Kiểm tra logo ở cỡ nhỏ, một màu và bản đảo màu bằng công cụ Python
- Đưa 3 concept rồi dừng chờ bạn chọn, không tự quyết thay

## Từ khóa

thiết kế logo, nhận diện thương hiệu, svg, logo

## Đầu vào

Brief thương hiệu/logo cần thiết kế

## Đầu ra

Ba concept logo và file SVG hoàn thiện của concept được chọn

## Giới hạn

Cần cài plugin marketplace; cần Python cho công cụ kiểm tra logo
