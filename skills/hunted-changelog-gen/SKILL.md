# changelog-gen

## Công việc

Tự động tạo CHANGELOG từ lịch sử Git

## Mô tả

Skill tạo CHANGELOG tự động từ Git history (从 Git 历史自动生成 CHANGELOG) trong repo claude-code-skills-zh: đọc các commit trong lịch sử Git của dự án rồi tổng hợp thành file CHANGELOG, giúp ghi lại thay đổi theo phiên bản mà không cần soạn tay.

## Điểm mạnh

- CHANGELOG bám đúng lịch sử commit thật, khỏi nhớ tay từng thay đổi
- Tiết kiệm thời gian soạn ghi chú phát hành mỗi lần release

## Từ khóa

changelog-gen, CHANGELOG, Git 历史, ghi chú phát hành, release

## Đầu vào

Lịch sử Git của dự án (commit log)

## Đầu ra

File CHANGELOG tổng hợp các thay đổi theo phiên bản

## Giới hạn

Chất lượng CHANGELOG phụ thuộc vào chất lượng commit message; commit viết cẩu thả thì CHANGELOG cũng khó đọc; cần kiểm tra lại trước khi phát hành
