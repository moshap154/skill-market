# huggingface-papers

## Công việc

Tra cứu và đọc paper trên Hugging Face Papers, tóm tắt và phân tích bài báo nghiên cứu AI

## Mô tả

Skill chính thức của Hugging Face: tra cứu và đọc trang paper của Hugging Face dưới dạng markdown, dùng papers API để lấy metadata có cấu trúc như tác giả, model/dataset/Space liên kết, repo GitHub và trang project. Dùng khi người dùng chia sẻ URL trang paper Hugging Face, URL hoặc ID arXiv, hoặc yêu cầu tóm tắt, giải thích hay phân tích một bài báo nghiên cứu AI. Hugging Face Papers (hf.co/papers) là nền tảng xây trên arXiv cho các bài báo AI/khoa học máy tính: mỗi ngày có feed Daily Papers, người dùng có thể upvote và bình luận; mỗi trang paper cho phép tác giả claim bài, liên kết checkpoint model, dataset, Space, repo GitHub và trang project. Repo gốc giấy phép Apache-2.0.

## Điểm mạnh

- Đọc trực tiếp nội dung paper dạng markdown từ trang HF Papers
- Lấy metadata có cấu trúc: tác giả, model/dataset/Space liên kết, repo GitHub
- Gắn với feed Daily Papers nên bắt kịp paper mới mỗi ngày

## Từ khóa

papers, arXiv, research paper, Hugging Face Papers, Daily Papers, tóm tắt paper

## Đầu vào

URL trang paper Hugging Face, URL/ID arXiv, hoặc câu hỏi về một bài báo nghiên cứu

## Đầu ra

Tóm tắt/giải thích/phân tích bài báo kèm metadata (tác giả, model/dataset/Space liên kết)

## Giới hạn

Thuộc hệ sinh thái Hugging Face; chỉ bao phủ paper trên HF Papers/arXiv, nội dung phụ thuộc trang paper công khai. Giấy phép Apache-2.0.
